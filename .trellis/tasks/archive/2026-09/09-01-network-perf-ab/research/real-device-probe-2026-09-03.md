# 真机分层探测报告（2026-09-03/04，用户实机，无 VPN 大陆网络）

来源：用户真机（5G/4G 移动网络，无 VPN）连续两轮「网络探测」页输出（00:25 与 00:42），
与最终体感确认（首屏 ≤1.5s、图片成批加载、滚动跟手）。

## 两轮探测原始结论（每 host 每层）

| host | 系统 DNS | DoH | TCP | TLS(真实SNI) | ECH | 空SNI(验证书) |
|---|---|---|---|---|---|---|
| app-api.pixiv.net | 污染 IPv6（2a03:2880:…，与 DoH 不一致） | ok（299ms → 67ms，104.18.42.239/172.64.145.17） | ok ~100ms | **RST(errno=104)** | **到达（404，1319ms → 530ms）** | 握手失败（Alert HandshakeFailure，CF 不认空 SNI） |
| oauth.secure.pixiv.net | 同上污染 | ok | ok ~90ms | RST | **到达（404，2832ms）** | 握手失败 |
| i.pximg.net | 污染 IPv6 | ok（8 个 210.140.139.x 源站地址） | ok（210.140.139.135, 169ms） | RST | **到达（403，1341ms → 1555ms）** | **到达（403，874ms → 162ms）** |
| s.pximg.net | 污染 IPv6 | ok（10 个 210.140.139.x） | ok（210.140.139.131, 158-216ms） | RST | **到达（404，1068-1351ms）** | **到达（404，874ms → 1999ms）** |

## 结论（驱动了 09-01 network-perf-ab 的最终排序）

1. **CF 域（API/OAuth）**：真实 SNI 被墙 RST；空 SNI 被 CF 拒绝；**ECH 是唯一可用且带
   HTTP/2 多路复用的路径**（首轮 ECH 到达 1.3s，第二轮 530ms——alidns 查询生效）。
2. **图片域**：真实 SNI 也被 RST；**空 SNI（DoH 活地址）与 ECH 都到达**。空 SNI 是
   HTTP/1.1（无多路复用），首屏 20 图＝20 连接，表现为"一片片补"；**改 ECH 优先后
   单连接 HTTP/2 多路复用**，图片成批出现（用户确认）。
3. **PixEz bootstrap 地址（210.140.139.155/133，无 SNI 无校验）在本轮探测页从未覆盖**，
   生产将其从第一候选降为最后兜底（未验证地址不再为每请求付 4s 连接超时）；
   成功一次后仍由 route/group memory 自动提升。
4. **系统 DNS 污染**（IPv6 段与 DoH 不一致）持续存在 → direct 档在任何严格档成功前
   不应作为首选（现为兜底位）。
5. 体感确认（用户）：首屏文字 ≤1.5s；图片批量出现；滚动跟手——网络层达标。
